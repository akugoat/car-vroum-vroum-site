User Data Deletion

Car vroum vroum does not store any user data on a server. The only data kept are access tokens, stored in a local file on the owner’s computer.

How to delete your data

  1. Instagram / Facebook: open Facebook → Settings & privacy → Settings → Apps and websites, find “Car vroum vroum” and click Remove. On Instagram: Settings → Apps and websites → Active → “Car vroum vroum” → Remove. The app immediately loses access and its tokens stop working.
  2. TikTok: open TikTok → Settings and privacy → Security → Manage app permissions, select “Car vroum vroum” and choose Remove access.
  3. The owner deletes the local token files when access is removed. No copy exists anywhere else.

For any question or deletion request, open an issue on GitHub.
